# Исходящий маршрут браузера флота

Необязательный локальный egress proxy позволяет выбирать рабочий маршрут для
отдельного браузерного профиля. Основной браузер и системные proxy settings
он не перенастраивает.

## Настройка оператора

Список маршрутов хранится локально в `data/secrets/fleet-egress.txt`, по строке:

```text
direct
http://proxy.example.net:8080
socks5://proxy.example.net:1080
```

Если маршруту нужна авторизация, добавьте её только в этот локальный секретный
файл. Не отправляйте его агентам и не коммитьте. Диагностический статус не должен
содержать логин или пароль маршрута.

Запускайте `tools/egress_proxy.py` своим лончером. Перед переключением браузера
проверьте bind/listen локального прокси. Профиль FleetChrome может использовать
`--proxy-server=http://127.0.0.1:8899`; адрес и запуск задаёт оператор.
Проверка внешнего маршрута обращается к `https://chatgpt.com/cdn-cgi/trace`.

В реестре флота доступность сети учитывается как ресурс. Отсутствующий ресурс
не должен создавать новые чаты и не считается неисправностью агента.
Переключение маршрута не является разрешением обходить ограничения аккаунта
или сервиса. Стандартный запуск dev-mcp не устанавливает автозапуск этого прокси.
