# Агент владельца во вкладке ChatGPT

Агент в вкладке владельца следит за флотом и ставит работу без Claude Code. Задач из очереди не
берёт — надзирает. Механика флота — [FLEET-PROTOCOL.md](FLEET-PROTOCOL.md); локальный пульт — `fleet.cmd`.

Роль открывает пульт `fleet_owner`. Записи и запуска в dev-mcp и правки `policy.toml` она **не
даёт**: агент, сломавший dev-mcp, не починит его через сломанный dev-mcp. Постоянного `freeze` и
ручного approve нет — блокеры оттаивают сами.

## Начало — без пароля и без слова «owner»

ChatGPT блокирует вызовы с паролем или просьбой поднять права ещё до сервера — и после этого весь
чат. Роль выдаёт владелец у себя на машине.

1. `fleet_join(label='pult')` → `worker_id`. Метка `pult…` нейтральна; расширение такую вкладку не
   запирает и не ведёт.
2. Агент пишет владельцу: «выдай роль W<N>». Владелец — двойной щелчок по `owner-grant.cmd` (Enter —
   выдать всем вкладкам pult без роли) или `fleet.cmd owner-grant [W<N>] [--hours N]` (по умолчанию
   12 ч); снять — `--revoke`. Выдача переживает перезапуск dev-mcp.
3. `fleet_owner(agent, 'status')`.

Чат, где уже заблокировали, не оживает — новый чат.

## Команды `fleet_owner(agent, команда, args)`

| команда | args | что делает |
|---|---|---|
| `status` | — | платформа, исключения, захваты, живые воркеры, очередь |
| `report` / `active` | `[ПРОЕКТ]` | заявлено против сделано / кто держит какие пути |
| `metrics` | `--since ГГГГ-ММ-ДД` | метрики потока |
| `bootstrap` | `ПРОЕКТ TZ-NN […] [--reactivate]` | поставить в очередь ТЗ из `ToDo/tz` проекта |
| `reactivate` / `recover` | `ПРОЕКТ TZ ПРИЧИНА` | вернуть frozen → ready / молчащий taken → ready с сохранением файлов |
| `priority` | `ПРОЕКТ N` | приоритет проекта (меньше — раньше) |
| `say` | `ТЕКСТ` | сообщение всем держателям задач — только о свершившемся факте |
| `lock` | — | закрыть свою сессию |

## Поставить работу

ТЗ — файлом `ToDo/tz/TZ-NN-коротко.md` с yaml-шапкой; как писать, чтобы прошло ревью с первого раза, —
[CLAUDE-CODE-FLEET.md](CLAUDE-CODE-FLEET.md#поставить-работу). Главное: единица ТЗ — законченный
вертикальный срез (реализация + тесты + встраивание), а не файл или хелпер; `owns` не пересекается с
задачами в работе (`active`). Затем `fleet_owner(agent, 'bootstrap', ['<Проект>', 'TZ-NN'])` — пустой
`errors` значит «в очереди», чат под неё откроет расширение.

## Что считать штатным

«Вернулась в очередь», «без ack», молчащий захват — штатно: молчащий захват maintenance вернёт сам
примерно через 30 мин; `recover` — аварийная кнопка. Авария — только платформа или транспорт, не
одна задача: сначала чинится инфраструктура, очередь продолжит сама.
