# Уроки флота — как опыт агентов доходит до правил (07.10.2026)

Код: `src/dev_mcp/fleet/lessons.py` (+ крючки в `judgment.py`, `tools._briefing`), мост к памяти —
`memory_service/mcp_server/fleet_memory.py`. Пульт: `fleet.cmd lessons`. Тесты: `tests/fleet/test_lessons.py`,
`memory_service/mcp_server/tests/test_fleet_memory.py`.

## Принципы (чтобы не чинить подтяжкой)

1. **Один журнал, ноль счётчиков.** Состояние — события реестра: `lesson_scan` (разбор отказа), `lesson_add` /
   `lesson_retire` (каталог), `lesson_shown` (что показано в памятке). Эффект урока, пул, версия каталога —
   запросы поверх них. Нечему разъезжаться.
2. **Контур замыкается итогом, который уже есть, — вердиктом ревьюера.** Не «агент честно зовёт
   record_rule_fired» (добровольное не срабатывает) и не LLM-судья по транскрипту (у флота транскриптов нет).
   Повторился ли класс дефекта у задач, которым урок показан, — это и есть «сработало».
3. **Каждый внешний вызов необязателен.** Нет ключа Jev — контур спит; сеть моргнула — повтор на следующем
   тике (5 мин); памятка без уроков — прежняя; мост к memory_service падает — сон идёт дальше. Память memory_service
   сейчас лежит (neo4j/ollama) — флот учится всё равно: доставка не идёт через граф.
4. **Доставка — push в памятку, а не pull из анонимной сессии.** Сервер знает агента, проект и ТЗ: «идентичность»
   и «домен выдачи» решены конструкцией. Ответ инструмента — самое сильное указание агенту.
5. **В граф — только с подтверждением владельца и только то, что доказало эффект или общее для проектов.**
   Правило-кусок промпта ≠ код: класс, который строка памятки не лечит, уходит архитектору в код/тест/шаблон ТЗ.

## Контур

| шаг | кто | что |
|---|---|---|
| разбор | `lessons.scan`, Jev | каждый новый reject задачи с acceptance (= утечка приёмки). Один вызов, два вопроса: «типовой механизм ошибки, а не недоделка пункта?» (`g`, порог 0,7) и choice по каталогу уроков проекта (порог 0,75). Известный класс → отказ записан за уроком; общий неизвестный → в пул |
| майнер | `lessons.open_mining` → `judgment` | пул проекта ≥ 5 → задача-суждение `lessons:<проект>` (одна открытая, 12 ч охлаждения, общий дневной бюджет triage). Агент кластеризует 20 последних отказов и пишет `ToDo/lessons/<id>.md`: class / rule / check / trigger / tier / scope / evidence. Кластеризация и формулировка — суждение LLM; оракул считает, не пишет |
| регистрация | `judgment.apply_accepted` | принятая triage → файлы уроков валидируются (длины, tier, scope) и становятся `lesson_add`; брак — в `errors` события `triage_applied`. `_none.md` с `class: none` — «классов нет» |
| доставка | `lessons.brief` в `tools._briefing` | при выдаче задачи Jev оценивает применимость каждого урока проекта (порог 0,7), в памятку — до 3 строк «класс. правило. Проверь: …». Выбор кэшируется на (задача, версия каталога). Ревьюеру — как «проверь на этих классах в первую очередь» |
| эффект | `lessons.effect` | вердиктов у показанных задач ≥ 8: повторов ≤ 10% — «работает», ≥ 25% — «не работает», между — «неясно». Показано/не показано в отчёте рядом |
| граф | `export_candidates` → `fleet_memory.agenda` | scope=global или tier=graph и не «не работает» → `data/fleet/lesson-candidates.json` в формате memory-save; сон memory_service кладёт в повестку «Кандидаты флота» с пометкой «ДУБЛЬ?» (Jev по ближайшим правилам). Пишет в граф memory-save после «да» владельца |
| шум чтения | `fleet_memory.noise_report` | доля доставленных флоту правил, которые задаче не нужны (Jev). Правила-шумители — в повестку сна: сужать `trigger` |

`tier`: `briefing` — поведенческий урок (строка в памятке); `code` — закрывается проверкой в проекте, в памятку
не идёт, в сводку сессии Claude Code («урок в код»); `graph` — как briefing, плюс кандидат в граф.

## Jev: где он нужен и почему именно он

Jev — быстрый (~0,4 с) оракул вероятностей по именованному вопросу о тексте; он не пишет, он считает. Поэтому он
стоит на объёмных узких местах: разбор каждого отказа, применимость урока к задаче, дедуп кандидата, шум
выдачи. Формулировки подобраны на живых данных: мягкое «может повториться» давало 0,8–0,9 почти всем
(62 из 72) и ничего не фильтровало; перечень механизмов и явное «нет» раздвинули оценки от 0,13 до 0,91.
Всё, что требует связного текста (кластер → правило), — агент-майнер (суждение через очередь, §6 v2).

## Что измерено до (07.10.2026, база для «после»)

`python fleet_memory.py noise --days 3 --queries 40` (memory_service/mcp_server; отчёты в `logs/fleet_noise/`):
**71% доставленных флоту правил не нужны задаче** (256 пар, 40 запросов). Шум не падает с ростом косинуса
(0,45 → 72%, 0,50 → 65%, 0,55 → 88%): порог не лечит. 12 правил-шумителей (ZeroTier, VPNNaruzhu, Claude
Desktop и т.п.) — доставляются ≥ 3 раза при ≥ 80% «не нужно». Лечение — сужение `trigger` этих правил в
сессии подтверждения сна; повторить замер после.
Разбор отказов на живом реестре: из 72 первых — 62 общих (по старой формулировке); по новой отсекается около
половины. Мягкость формулировки — единственное, что надо перемерить, когда накопятся первые уроки.

## Что сознательно не сделано

- **Эскалации «дыра в ТЗ»** не разбираются: нет канала доставки уроков авторам ТЗ (памятка автора ТЗ не
  отдельный объект). Источник добавляется в `scan` и канал — строкой в шаблон ТЗ, когда он появится.
- **Фильтр Jev внутри `recall`** не ставился: он прятал бы плохие правила, не чиня их, а память сейчас лежит —
  проверить нечем. Если после сужения триггеров шум останется высоким — включать флагом для запросов флота.
- **Идентичность в самом `recall`** не вводилась: личность уже в тексте запросов (проект, ТЗ, воркер — 85% /
  12%), `fleet_identity()` читает её при разборе журнала. Сервер recall не тронут.

## Эксплуатация

- `fleet.cmd lessons` — каталог, эффект каждого урока, пул по проектам.
- `fleet.cmd lessons add ФАЙЛ --project П` — урок вручную (владелец / Claude Code, формат как у майнера).
- `fleet.cmd lessons retire П/id` — снять. Агентский урок читают все следующие агенты проекта — длины урока
  ограничены, а видно его здесь и в `lesson_add` реестра.
- Пороги — константы в начале `lessons.py`; менять по данным `fleet.cmd lessons`, не по ощущению.
