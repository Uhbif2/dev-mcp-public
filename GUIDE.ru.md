# Как пользоваться dev-mcp

[English](GUIDE.md) · [Установка агентом](AGENT-SETUP.md)

dev-mcp — сервер для Windows и флот кодовых агентов во вкладках вашего ChatGPT. Обычная очередь резервирует файлы, фиксирует приёмку и отдаёт работу независимому ревьюеру. Быстрые агенты выполняют небольшие поручения в заданных границах без очереди. Ночное ревью по желанию ищет проблемы кода, продукта и документов; надзор следит за ходом выбранного разговора при наличии бэкенда решений.

Скажите своему локальному агенту: «Поставь эту задачу флоту с приёмкой и независимым ревью» или «Отдай небольшую задачу быстрому агенту и проверь результат». Вручную управлять очередью не нужно. Ход работы виден во вкладках, в popup и на бейдже Fleet Tabs. Из каталога установки команда fleet.cmd показывает состояние; fleet.cmd result Demo/TZ-1 — итог конкретной задачи.

Если что-то сломалось, попросите агента выполнить три команды из каталога установки:
```powershell
.venv\Scripts\python.exe tools/standalone.py doctor
.\fleet.cmd
.venv\Scripts\python.exe tools/fleet_chrome.py status
```
Если локально всё работает, а инструменты ChatGPT исчезли, переподключите авторизованный коннектор. Подробности — [AGENT-SETUP.md](AGENT-SETUP.md); журнал сервера — logs/standalone.log.

Не давайте широких прав в policy.toml, не выставляйте сервер через публичный туннель без авторизации, не отправляйте пароли и токены агентам. Запись вместе с запуском означает выполнение кода с правами вашего пользователя Windows: выделяйте отдельные рабочие папки и доверяйте только проверенным агентам. Не обходите проверки человека и предупреждения сервиса. [Безопасность](SECURITY.md).
